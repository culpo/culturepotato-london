# culturepotato-london

Listings data for **On View London** — an AI project by 文化土豆 Culture Potato, live at [culturepotato.com/london](https://culturepotato.com/london/).

`exhibitions.json` holds the current exhibitions at 24 London museums and galleries: venues (with map coordinates) and exhibitions (headline, official title, leading artists, dates, admission, links, and a sinophone tag).

The page on culturepotato.com reads this file directly. It is rewritten by an on-demand refresh that re-reads each venue's own website; listings are gathered and written up with AI, so check details with the venue before you travel.
